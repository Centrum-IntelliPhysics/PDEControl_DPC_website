Learning to Control PDEs with Differentiable Predictive Control and Time-Integrated Neural Operators

Dibakar Roy Sarkar, Ján Drgoňa*, Somdatta Goswami*
Johns Hopkins University, Whiting School of Engineering
*Advised equally
arXiv PDF Code Data Cite

A TI-DeepONet learns the PDE dynamics and stays differentiable, so the optimal-control loss can be backpropagated through an entire closed-loop rollout to fit a neural policy, offline, self-supervised, and with no supervisory controller.

Abstract

We present a data-driven control framework for partial differential equations (PDEs). Our approach integrates Time-Integrated Deep Operator Networks (TI-DeepONets) as differentiable PDE surrogate models within the Differentiable Predictive Control (DPC), a self-supervised learning framework for constrained neural control policies. The TI-DeepONet architecture learns temporal derivatives and couples them with numerical integrators, while the DPC algorithm uses automatic differentiation to compute policy gradients by backpropagating the expectations of the optimal control loss through the learned TI-DeepONet. This approach enables efficient offline optimization of neural policies without the need for online optimization or supervisory controllers. We empirically demonstrate the proposed method across diverse PDE systems, including the heat, the nonlinear Burgers', and the reaction-diffusion equations. The learned policies achieve target tracking, constraint satisfaction, and curvature minimization objectives, while generalizing across distributions of initial conditions and parameters. Moreover, we demonstrate four orders of magnitude acceleration at inference time compared to nonlinear model predictive control benchmarks. These results highlight the promise of operator learning for scalable model-based control of PDEs.

How it works

1

Learn a differentiable surrogate

A TI-DeepONet predicts the temporal derivative of the state rather than the next state directly, and is composed with an RK4 integrator. Keeping the integrator explicit preserves temporal causality and limits error accumulation over long horizons. That is what makes the surrogate trustworthy enough to differentiate through for hundreds of steps.

2

Backpropagate through the rollout

The surrogate is frozen. The optimal-control loss is evaluated on a full closed-loop rollout and its gradient flows back through every integration step to the policy parameters. No labelled control data, no supervisory controller, and no optimization at deployment. The policy is a single forward pass.

Every system is actuated by Gaussian sources whose amplitudes the policy sets at each step: $f(x,t)=\sum_i c_i(t)\,\exp\!\left(-\frac{(x-x_i)^2}{2\sigma^2}\right)$

Inference speed

Because the policy is a single forward pass, deployment costs a network evaluation instead of solving an optimization problem at every step. Against nonlinear MPC benchmarks the paper reports four orders of magnitude of acceleration.

Nonlinear MPC needs seconds per control step because it solves an optimization problem online. The learned policy needs tenths of a millisecond, while reaching comparable tracking error. Across the three systems that is a speedup of roughly 1.7×104, 4.4×104 and 3.3×104.

Try it yourself

Pretrained checkpoints are in the repository, so the demo notebooks run on CPU in a few minutes with no dataset download. 

git clone https://github.com/Centrum-IntelliPhysics/PDEControl_DPC.git
cd PDEControl_DPC
pip install -r requirements.txt

cd HE_TT && jupyter notebook 01_control_demo.ipynb

  01_control_demo.ipynb

Loads the pretrained policy, generates fresh test cases, and validates on the true numerical solver. Change one SEED for a new set of test cases.

  02_train_dpc.ipynb

Trains a policy from scratch through the frozen TI-DeepONet. Short schedule by default so it finishes quickly on CPU.

The ~2.4 GB training datasets, needed only to retrain a surrogate from scratch, are on Hugging Face, fetched with python download_data.py.
